# 买多了退不掉（material-pick）

装修买料之前，先算清「到底要买多少件」。

瓷砖不是「房间面积 ÷ 砖面积」就完事——边上一圈要切，切剩的那条能不能挪去别处，
直接决定你多买几块。地板只能整箱买、乳胶漆只能整桶买、美缝按管买，这里把它们一起摊平。

## 它算什么

- **地面砖 / 墙砖**：按房间尺寸做网格整除（含缝隙的有效模数），算清整砖几块要切、
  边界上切剩的那条有多宽、够不够宽到能留下当边角料；再按备用量给出采购块数。
  墙砖会按门窗洞口占墙面的比例折减。
- **地板**：按面积加余量，再按「每箱几片」拆包取整，并算出最后一行要切掉多少毫米。
- **刷墙三件套**（乳胶漆 / 腻子 / 界面剂）：墙面净面积 + 天花板，乘可使用系数，
  乳胶漆再乘遍数、按整桶取整。
- **踢脚线**：周长扣门洞，按每根长度取整；可以对照瓷砖边角料够不够。
- **美缝剂**：缝长按有效模数数出来（不是房间周长），按每管米数取整。

## 口径纪律

- 「买来的比用掉的多几成」与「买回来的料里有多少切没了」**分母不同**，页面分两列显示。
- 默认值与所有内置场景**都是虚构示例**。
- 页面**不联网**、不查行情价、不内置任何施工规范，你填的数字只存在你自己的浏览器里。

## 不算什么

- 不做面积测绘；不支持菱形铺、人字拼、斜铺、六角砖、拼花、波导线、过门石单独算料。
- 不做水泥、沙子、砖块、防水、水电改造的用量（需要现场路由或真实配比规范）。
- 不做壁纸 / 壁布用量。
- 覆盖率、腻子用量、可使用系数、边角料阈值都是本页的设计取值，**不是标准、不是厂商数据**。

## 结构

- `index.html` —— 单文件应用（由 `template.html` 内联 `core.js` 与 `ui.js` 生成）
- `core.js` —— 纯函数计算引擎（`AppCore.compute`），无 DOM 依赖
- `ui.js` —— 决策树式输入 + 采购清单式输出、四种导出与本地保存
- `tests/core.test.cjs` —— 核心测试：`node --test tests/core.test.cjs`
